# @carefully-built/kanban

Reusable Kanban primitives for SaaS pipelines.

## Includes

- `KanbanBoard` with columns, drag/drop callbacks, mobile move drawer support, empty-column actions, and pipeline total.
- `KanbanCard` with title, associations, value, tooltip details, edit/delete actions, and mobile move sheet.
- `buildKanbanColumns` and `resolveKanbanSelection` helpers for config-driven pipelines.

Use app-side adapters for mutations, route building, copy, and domain-specific metadata.
