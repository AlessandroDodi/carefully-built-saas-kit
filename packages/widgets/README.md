# @carefully-built/widgets

Reusable dashboard and detail widgets for Carefully Built SaaS apps.

## Components

- `WidgetEmptyState`: dashed empty-state panel with optional action.
- `EntityInfoWidget`: compact bordered info widget with icon, title, actions, content, and empty-state support.
- `DashboardWidget`: dashboard card shell that keeps icon/title visible while loading and skeletonizes only the value/body.

Use this package when a new app needs the same SaaS widget chrome without rewriting loading, empty, title, icon, and action behavior.
