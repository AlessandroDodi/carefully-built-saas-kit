# @carefully-built/maps-ui

Reusable Google Maps helpers for SaaS apps.

## Exports

- `loadGoogleMapsApi`, `loadGoogleMapsPlacesApi`, and typed Google Maps wrappers.
- `GOOGLE_MAP_THEME_STYLES` for the shared map theme presets.
- `GoogleMapsPhotoAttribution` for compact Google photo attribution UI.

Use this package when an app needs a map selector, map preview, entity map, location selector, or Google Places autocomplete without rewriting loader and theme plumbing.
